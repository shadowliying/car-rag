## 四、你下一步最该补的 5 个重点

按优先级排。

### 第一优先级：把“数据集可信性”补硬
你接下来必须能非常顺地回答：

- 2000 条 query 怎么来的
- 哪些是人工种子，哪些是 GPT 扩写
- answer 是怎么标的
- 扩写后的 query 和 answer 对齐怎么保证
- train/val/test 怎么切
- 为什么不会泄漏
- hard negative 是怎么来的
- 为什么你能信这批数据

你现在最缺的不是“数据多少”，而是“数据为什么可信”。

### 第二优先级：把 Embedding 和 Rerank 微调彻底区分开
你必须形成固定口径：

- Embedding 微调：
  - Bi-Encoder
  - 三元组
  - Triplet / Contrastive
  - 目标是 Recall
- Rerank 微调：
  - Cross-Encoder
  - `(Q, D, label)`
  - Pointwise BCE
  - 目标是 Precision / 排序前移

这个你要练到“别人一打断你，你也不混”。

### 第三优先级：把“融合逻辑”改成更稳的说法
你以后不要把“固定权重融合”讲得太重。

最稳说法改成：

- 两路先各取 Top15
- 合并去重形成候选池
- 加权融合做过实验，但不是主收益点
- 真正排序靠 Rerank
- 如果讲权重，强调是“归一化后在验证集上调出来的”
- 特殊 query 可以动态调权，这是优化方向

这样就不会再被“BM25 权重低了那缩写怎么兜底”这类问题反杀。

### 第四优先级：把 ranking 指标体系彻底理顺
你之后必须形成这个反射：

- 召回层：Recall@K、MRR、Hit Rate
- Rerank 层：MRR、NDCG、Precision@K、Recall@K
- 端到端：系统准确率

然后明确：

- `precision@6` 不是不能讲
- 但不能单独作为主亮点
- 因为真实相关文档数有限，它有天然上限问题

你最好以后主打：

- `MRR`
- `NDCG`
- `top1 / top3 命中`
- 端到端准确率

### 第五优先级：把 PDF 解析异常场景补齐
你昨天明显在这些题上虚了：

- 标题层级错怎么办
- 叶子节点太短怎么办
- 结构树错怎么办
- 扫描 PDF 和普通文本 PDF 差别怎么办

这一类你要补成“异常处理模板题”。
